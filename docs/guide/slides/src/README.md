# Claude Code for engineers

A beginner-friendly tour for people who already ship software.

1. **What it is:** the agent, the loop, the context window
2. **Steering it:** prompts, `CLAUDE.md`, permissions, plan mode
3. **Extending it:** skills, subagents, hooks, MCP, plugins
4. **Automating it:** headless runs, CI, parallel sessions
5. **Examples:** from one-liners to the plugins in this repository

Press **→** or **Space** for the next slide, **←** to go back. The house icon above opens the [landing page](../index.html).
