# Habits that pay off

1. **Give it a check.** A test or a build turns "looks right" into "is right"
2. **Plan first** when the change is large or the code is unfamiliar
3. **`/clear` between tasks.** Stale context costs money and accuracy
4. **Keep `CLAUDE.md` short.** Write down what the repository cannot tell
5. **Enforce with hooks,** guide with prompts
6. **Correct early.** `Esc` and redirect beats waiting for a wrong result
7. **Review the diff.** `/diff`, then `/code-review` for an independent read
8. **Watch the meter.** `/usage` shows what a session cost

<small>Source: [Best practices](https://code.claude.com/docs/en/best-practices)</small>
