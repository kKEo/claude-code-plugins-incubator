# What Claude Code is

> "An agentic coding tool that reads your codebase, edits files, runs commands, and integrates with your development tools."

- Not autocomplete and not a chat window: an **agent** that works in your repository with your tools
- You describe an outcome; it finds the files, makes the change, runs the check
- The model reasons; Claude Code is the **harness** around it: tools, context, permissions
- You stay in charge: every action passes through a permission mode you choose
