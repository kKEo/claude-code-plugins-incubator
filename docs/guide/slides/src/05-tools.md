# Tools: how it acts

Models reason; **tools act**. Without tools a model can only answer in text.

| Category | Examples |
|---|---|
| File operations | read, edit, create files |
| Search | find files by pattern, search contents |
| Execution | shell commands, tests, git |
| Web | search the web, fetch documentation |
| Code intelligence | type errors after edits, go to definition (via plugins) |

Delegating to a subagent and asking you a question are tools too. Extensions add more.

<small>Source: [How Claude Code works](https://code.claude.com/docs/en/how-claude-code-works)</small>
