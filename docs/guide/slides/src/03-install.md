# Install and first run

```bash
# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

# or: brew install --cask claude-code
# or: winget install Anthropic.ClaudeCode

claude --version
cd your-project && claude
```

- The first run asks you to log in: a Claude subscription, a Console account, or a cloud provider
- Then just type: `what does this project do?`
- `/help` lists commands, `/doctor` checks the setup

<small>Source: [Quickstart](https://code.claude.com/docs/en/quickstart)</small>
