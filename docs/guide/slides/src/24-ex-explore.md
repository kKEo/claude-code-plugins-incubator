# Basic: learn a codebase

Day one on an unfamiliar repository. No setup, read-only.

```text
what does this project do?

where is the entry point, and how does a request reach the database?

Explain the logic in @src/utils/auth.js

use a subagent to investigate how our auth system handles token refresh
```

- Claude searches and reads on its own; you do not paste files
- `@` pins a file; the subagent keeps a long search out of your context
- Finish with `/init` to save what it learned into a starter `CLAUDE.md`
