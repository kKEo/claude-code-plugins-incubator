# This repo: the marketplace

This repository **is** a marketplace: `km-plugin-registry`, eleven plugins.

```text
/plugin marketplace add kKEo/claude-code-plugins-incubator
/plugin install rigorous-review@km-plugin-registry
/reload-plugins
```

| Kind | Plugins |
|---|---|
| Skills and agents | `rigorous-review`, `implementation-spec`, `gitbook-docs`, `frontend-scaffold`, `feature-dev-documentalist`, `session-cost-installer` |
| Hooks | `memors-hooks` |
| Mods | `session-cost`, `plan-progress`, `prompt-coach`, `instances-monitor` |

The whole registry is one file: `.claude-plugin/marketplace.json`.
