# Where it runs

| Surface | What you get |
|---|---|
| **Terminal** | The full CLI: `claude` in any project folder |
| **VS Code** | Extension with inline diffs, @-mentions, plan review |
| **JetBrains** | Plugin that runs the CLI in the IDE terminal |
| **Desktop app** | Visual diff review, parallel sessions, scheduled tasks |
| **Web and mobile** | `claude.ai/code`, no local setup |

One engine behind all of them: `CLAUDE.md`, settings and MCP servers carry across.

<small>Source: [Overview](https://code.claude.com/docs/en/overview)</small>
