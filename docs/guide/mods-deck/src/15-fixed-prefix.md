# What was sent is fixed

The limit that surprises people most. A mod cannot change what the model has already been sent; it adds new context at the end.

![What a thread has already sent is fixed: the system prompt, the tool descriptions and the earlier messages stay as they are; a mod adds new context as a new row at the end; the prompt cache is keyed on the prefix, so changing it makes every later request pay full price](../operator/images/fixed-prefix.svg)
