# This repo: prompt-coach

A `prompt.submit` hook that only watches, a model call in the background, and a store: your prompt is never delayed or changed.

![How prompt-coach works: you type a prompt, the mod collects it and asks a correction model to proofread it in the background, keeps the result in the plugin store, shows a toast and fills the Prompts and Practice tabs](../user/images/how-prompt-coach.svg)
