# Claude Code mods

A beginner-friendly tour of mods for people who already ship software: code of yours, loaded into Claude Code, that changes its interface and what flows through a session.

![The four parts of this deck: what a mod is; how it works, with the hook chain, events and the engine interface; building one; and examples, from ten lines to the four mods of this repository](images/agenda.svg)

Press **→** or **Space** for the next slide, **←** to go back. The house icon above opens the [landing page](../index.html).
