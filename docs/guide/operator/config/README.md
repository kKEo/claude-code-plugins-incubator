- [plugin.json](plugin-json.md): a plugin's manifest.

- [Agent frontmatter](agent-frontmatter.md): the YAML header of an agent file.
- [Hooks](hooks.md): `hooks.json`, events, the script wrapper and environment variables.
- [Commands and flags](commands.md): slash commands and the validator CLI.
