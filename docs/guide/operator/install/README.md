# Part II: Install and deploy

Four chapters cover the life of a plugin from a local checkout to a published release.

- [Local development](local-dev.md): run a plugin from your working copy and reload it after each edit.
- [Installing from the marketplace](marketplace.md): the user-facing install path and what it does on disk.
- [Publishing a plugin](publish.md): add a new plugin directory and a manifest entry, then open a pull request.
- [Releasing a new version](release.md): bump the version, record the change, tag.
