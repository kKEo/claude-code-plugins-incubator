# Is it safe?

A fair question for anything you install. The honest answer: treat a mod like any other program.

![A mod is real code: it runs on your machine with your own rights, like any program you install. Choose your source: install mods from people you trust or whose code someone has read. You stay in control: turn a mod off or remove it at any time, and an organization can restrict which mods load.](images/safe.svg)
