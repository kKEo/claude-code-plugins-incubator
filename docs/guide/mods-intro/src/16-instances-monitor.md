# instances-monitor

Lists every Claude Code session running on your machine, so you can follow several at once from one place.

![Workflow of instances-monitor: Claude Code keeps a session file per instance, the mod lists them, checks which are alive and draws the pane](../user/images/workflow-instances-monitor.svg)
