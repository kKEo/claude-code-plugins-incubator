# Stop risky actions

A mod sees each action Claude is about to take, and can stop it or adjust it before anything happens.

![When Claude wants to edit a protected file, the mod stops the edit before it happens and Claude is told why. When Claude wants to edit an ordinary file, the edit goes ahead as usual. Unlike a written instruction, a guard is not something Claude can forget.](images/guard.svg)
