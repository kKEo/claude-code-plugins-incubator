# Six kinds of extension

Skills, agents, slash commands, hooks and connectors change what **Claude** knows and can reach. A mod changes the **app** you are sitting in.

![A skill teaches Claude: a written procedure Claude follows. An agent is a specialised helper Claude hands a task to. A slash command is a shortcut you type yourself. A hook is a small script Claude Code runs by itself at a fixed moment. A connector, also called an MCP server, connects Claude to another system. A mod changes Claude Code itself: what you see on screen and what is allowed to happen. A plugin is the package that delivers any of them.](images/six-kinds.svg)
