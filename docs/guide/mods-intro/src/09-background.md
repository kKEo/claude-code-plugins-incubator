# Work in the background

A mod does not have to wait for you to type. It can keep watch on a timer and speak up when something changes.

![Every minute, with no prompt from you, the mod checks something, for example whether your build passed. While it passes, a quiet line under the prompt says so. When it fails, you get a notification and Claude can be asked to look.](images/background.svg)

<small>Source: [Mods API](https://code.claude.com/docs/en/plugins/mods/api)</small>
