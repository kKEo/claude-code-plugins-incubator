# Add commands and buttons

A mod brings its own slash commands, and its panels can have buttons, tabs and text fields.

![You type a slash command the mod added, for example slash session-cost. The mod answers: it opens its panel or prints a line. Inside the panel you press its buttons to switch views.](images/commands.svg)

<small>Source: [Mods overview](https://code.claude.com/docs/en/plugins/mods/overview)</small>
