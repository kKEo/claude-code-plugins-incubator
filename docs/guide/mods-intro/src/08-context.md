# Give Claude context

A mod can hand Claude the facts it needs together with your prompt, so you do not have to repeat them.

![You type a prompt such as fix the failing test. The mod quietly adds facts Claude should know, such as the current branch and the house rules of the project. Claude reads both. You see your own prompt, unchanged.](images/context.svg)

<small>Source: [Hook into events](https://code.claude.com/docs/en/plugins/mods/events)</small>
