# No code needed

You do not have to write a mod yourself. Describe what you want to see, and Claude builds it.

![You describe the mod in a sentence. Claude writes it and asks once before turning it on. The mod appears in your session, and reloads each time Claude edits it.](images/ask-claude.svg)

<small>Source: [Create a mod](https://code.claude.com/docs/en/plugins/mods/create)</small>
