# Three kinds of extension

Skills and connectors change what **Claude** knows and can reach. A mod changes the **app** you are sitting in.

![A skill teaches Claude: a written procedure Claude follows. A connector, also called an MCP server, connects Claude to another system. A mod changes Claude Code itself: what you see on screen and what is allowed to happen. A plugin is the package that delivers any of them.](images/three-kinds.svg)
