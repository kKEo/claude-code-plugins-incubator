# Before and after

A mod is a small add-on that changes Claude Code itself: it puts your own information on the screen, next to the conversation.

![On the left, Claude Code as it ships: a conversation and a prompt box. On the right, the same session with mods: a panel beside the conversation showing a plan, a row of facts above the prompt, and a status line under the prompt showing the cost so far.](images/before-after.svg)
