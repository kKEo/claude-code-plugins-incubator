# Glossary

Testing terms used in this handbook. Ledger terms are in the [internals glossary](../../internals/appendix/glossary.md).

| Term | Meaning |
|---|---|
| Acceptance test | A check run by a tester against a running service, from this handbook |
| Blocker | A defect that stops a release |
| Build under test | The exact version of ledgerd being checked |
| Invariant | Something that must be true at all times, such as debits equalling credits |
| Regression | Something that worked in an earlier release and no longer does |
| Scratch ledger | A throwaway ledger in an empty `LEDGERD_HOME`, used for one test run |
| Test case | A numbered set of steps with one expected result |
