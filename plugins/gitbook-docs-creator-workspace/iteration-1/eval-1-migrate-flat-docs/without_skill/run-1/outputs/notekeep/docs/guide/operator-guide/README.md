# notekeep Operator Guide

This book is for people who install, run and develop notekeep. It covers how the server is
built and how to keep it running.

* [Architecture](architecture.md): the process, the table and how requests are handled.
* [Configuration](configuration.md): every environment variable.
* [HTTP API](http-api.md): endpoints, status codes and errors.
* [Deployment](deployment.md): systemd, the reverse proxy and the health check.
* [Backup and maintenance](backup-and-maintenance.md): backups, compaction and removing notes.

Source: <https://github.com/example/notekeep> (Apache-2.0).
