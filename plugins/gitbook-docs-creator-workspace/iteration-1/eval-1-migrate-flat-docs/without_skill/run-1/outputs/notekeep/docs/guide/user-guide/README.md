# notekeep User Guide

notekeep is a tiny notes server for a team. It keeps notes in one SQLite file and gives you a
JSON API and a command line tool.

This book is for people who want to keep notes in notekeep. It assumes no knowledge of how
the server works inside.

* [Getting started](getting-started.md): run notekeep and save your first note in about two
  minutes.
* [Using notekeep](using-notekeep.md): save, list, read and export notes.
* [FAQ](faq.md): answers to common problems.

If you run notekeep for other people, read the Operator Guide. If you change notekeep's code,
read the Tester Guide.
