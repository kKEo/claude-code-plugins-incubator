notekeep

A tiny notes server for a team. It keeps notes in one SQLite file and gives you a JSON API and a command line tool. Pick the book written for you.

User Guide

For people who keep notes

Start the server, save your first note, then list, read and export notes.

Operator Guide

For people who run and develop notekeep

Architecture, configuration, the HTTP API, deployment, backup and maintenance.

Tester Guide

For contributors and reviewers

Run the test suite, see what it covers, and learn what runs on a pull request.
