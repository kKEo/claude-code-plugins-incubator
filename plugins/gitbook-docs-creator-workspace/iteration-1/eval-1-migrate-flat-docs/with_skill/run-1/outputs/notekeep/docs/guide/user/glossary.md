# Glossary

These are the words this guide uses, in alphabetical order.

**Address.** The text that starts with `http://` and tells `curl` where notekeep is, for
example `http://localhost:7070`.

**curl.** A small program that sends a request from the terminal. This guide uses it to
save and list notes.

**Export.** Writing every note to its own file, so that you can keep or move them.

**Note.** A piece of text that notekeep keeps for you under a title.

**Terminal.** The window on your computer where you type commands.

**Title.** The name of a note. It is the last part of the address when you save, and no two
notes have the same one.

**Token.** A password shared by the team. When notekeep asks for it, you add it to each
`curl` command.
