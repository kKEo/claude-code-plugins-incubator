# Welcome

**notekeep keeps short notes for you or your team, in one place, under titles you choose.**

This guide is for anyone who uses notekeep. It assumes no technical background.

You save a note by sending a line of text under a title, and you get a list of all notes
with the time each was last saved. Saving again under the same title replaces the note, so
a shared note always shows the latest text.

notekeep is small on purpose. It runs on one computer, keeps everything in one file there
and sends nothing anywhere else. You use it by typing short commands; this guide shows each
one.
