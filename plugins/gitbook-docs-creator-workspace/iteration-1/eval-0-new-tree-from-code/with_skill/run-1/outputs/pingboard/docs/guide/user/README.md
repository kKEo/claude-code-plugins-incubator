# Welcome

**pingboard watches a list of web addresses for you and shows, on one page, which ones are working right now.**

You give pingboard the addresses you care about: your website, a shop, a page your team depends on. Every minute it visits each one, the way a browser would, and notes whether it answered and how fast.

The result is a simple page, called the dashboard, with one line per address that says `up` or `DOWN`. You can also ask pingboard to check everything once, right now, and tell you the answer in the terminal.

pingboard runs on your own computer. It keeps your list in one small file and sends nothing about you anywhere.

This guide is for anyone who uses pingboard. It assumes no technical background, only that you can open a terminal and type a command.
