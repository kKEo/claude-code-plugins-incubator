# Glossary

The words this guide uses in a special sense, in alphabetical order.

**Address.** The text you type into a browser to reach a web page, such as `https://example.org`.

**Check.** One visit by pingboard to one web page, to see whether it answers.

**Command.** A line you type in a terminal to make a program do something, such as `pingboard list`.

**Dashboard.** The page pingboard shows in your browser, with one line for each web page you watch.

**DOWN.** What pingboard shows when a web page answered with an error or did not answer in time.

**Target.** A web page you have asked pingboard to watch.

**Terminal.** The window on your computer where you type instead of clicking.

**Up.** What pingboard shows when a web page answered without an error.
