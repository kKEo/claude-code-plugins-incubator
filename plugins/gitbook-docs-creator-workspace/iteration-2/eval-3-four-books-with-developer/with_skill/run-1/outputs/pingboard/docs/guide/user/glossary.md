# Glossary

These are the words this guide uses in a special sense, in alphabetical order.

**Address.** The location of a website, such as `https://example.org`, as you would type it in a browser. The other guides call an address in your list a target.

**Check.** One attempt by pingboard to reach a website and see whether it answers.

**Dashboard.** The page pingboard shows in your browser, with one row for each website you watch.

**Down.** The state of a website that did not answer in time, or answered with an error. Shown as `DOWN`.

**JSON.** A text format that programs can read easily. `pingboard check --json` prints its results in it.

**List.** The websites you asked pingboard to watch. It is kept in one file on your computer.

**Port.** A number at the end of the dashboard's location, such as the `8080` in `http://127.0.0.1:8080/`. It lets several programs on one computer each have their own page.

**Status.** The number a program reports when it ends, or a website sends with its answer. For `pingboard check`, 0 means every website answered and 1 means at least one did not.

**Terminal.** The program on your computer in which you type commands.

**Up.** The state of a website that answered in time and without an error.
