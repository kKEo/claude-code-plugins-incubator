# Welcome

**pingboard checks your websites once a minute and shows you, on one page, which ones are up.**

You give pingboard a list of web addresses. It visits each one regularly, the way a browser would, and notes whether the website answered and how quickly. A page in your browser, the dashboard, shows the result for every address.

You can also ask it to check everything once, right now, and print the answer. That is handy after you changed something, or inside a script.

pingboard runs on your own computer. It keeps your list in one small file and sends nothing anywhere except the visits to the addresses you chose.

This guide is for anyone who uses pingboard. It assumes no technical background.
