# Glossary

The words this guide uses, in alphabetical order.

**Address.** Where notekeep can be reached, such as `http://localhost:7070`. The part after
the last `/` in a save command is the name of your note.

**Export.** Writing every note into a folder as a separate text file.

**localhost.** A name that means "this computer". An address with `localhost` reaches
notekeep only when it runs on the computer you are typing on.

**Note.** A piece of text saved in notekeep under a name.

**Port.** The number at the end of an address, such as `7070`. It tells your computer which
program to talk to.

**Terminal.** The window where you type commands.

**Title.** The name of a note. No two notes have the same one.

**Token.** A shared password. When notekeep was started with one, you must send it with
every command that saves or lists notes.
