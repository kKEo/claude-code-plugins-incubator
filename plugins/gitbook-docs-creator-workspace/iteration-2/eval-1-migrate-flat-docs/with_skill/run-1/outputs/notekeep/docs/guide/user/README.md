# Welcome

**notekeep keeps your team's notes in one place, so that everyone can save a note and see the list from their own computer.**

This guide is for anyone who uses notekeep. It assumes no technical background.

A note is a piece of text with a title, such as a shopping list called "shopping". You save
a note by sending its text to notekeep, and you save again under the same title to replace
it.

notekeep is small on purpose. It runs as one program on one computer and keeps every note
in a single file there. Nothing is sent anywhere else.

You talk to notekeep by typing short commands. This guide shows each one in full, so you
can copy it.
