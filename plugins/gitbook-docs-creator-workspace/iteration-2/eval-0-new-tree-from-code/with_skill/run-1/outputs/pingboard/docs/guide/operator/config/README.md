# Part III: Configuration reference

This part is for looking things up. Each chapter is a complete list of one kind of thing, taken from the code; read them in any order.

- [Environment variables and settings](environment.md): which settings exist, their defaults and what an invalid value does.
- [Commands and flags](commands.md): what each subcommand does, what it prints and how it exits.
- [Files on disk](files.md): which files pingboard writes and what the targets file looks like.
- [HTTP routes](routes.md): what the server of `serve` answers on each path.
