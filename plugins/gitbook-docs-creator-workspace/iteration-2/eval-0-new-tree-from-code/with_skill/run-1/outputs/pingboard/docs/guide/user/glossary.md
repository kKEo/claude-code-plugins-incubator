# Glossary

The words this guide uses with a special meaning, in alphabetical order.

**Address.** What you type in a browser to open a website, such as `https://example.org`.

**Check.** One attempt by pingboard to open an address and see whether it answers.

**Dashboard.** The page in your browser where pingboard shows the state of everything it watches.

**Down.** The website did not answer in time, or answered with an error. Shown as `DOWN`.

**Interval.** The pause between two rounds of checking. It is 60 seconds unless you change it.

**Status.** The number a website sends back with its answer. Numbers below 400 mean the request worked; `0` means there was no answer at all.

**Target.** An address you have asked pingboard to watch.

**Terminal.** The window on your computer where you type commands.

**Up.** The website answered without an error the last time pingboard asked.
