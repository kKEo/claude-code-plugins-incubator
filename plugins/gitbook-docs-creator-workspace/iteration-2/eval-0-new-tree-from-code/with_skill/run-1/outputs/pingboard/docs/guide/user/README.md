# Welcome

**pingboard watches a list of web addresses for you and shows, on one page, which ones are up.**

This guide is for anyone who uses pingboard. It assumes no technical background.

You give pingboard the addresses you care about. Once a minute it tries to open each one, the way a browser would, and notes whether it answered and how long that took.

You see the result in two ways: as a table in your browser, called the dashboard, or as a few lines of text when you ask for a check right now.

pingboard runs on your own computer and keeps only your list of addresses. You use it by typing short commands; this guide shows each one.
