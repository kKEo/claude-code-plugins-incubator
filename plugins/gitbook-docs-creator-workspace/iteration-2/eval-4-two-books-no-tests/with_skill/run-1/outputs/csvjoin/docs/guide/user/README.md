# Welcome

**csvjoin combines two CSV files into one table, matching the rows by a column they share.**

This guide is for anyone who uses csvjoin. It assumes no technical background.

Suppose one file lists people and another lists the city each person lives in, and both
have an `id` column. csvjoin puts each person's city next to their name and gives you one
table.

You use csvjoin by typing one short command in a terminal, the window where you type
commands. You name the two files and the column they share. The result appears on the
screen, or in a new file if you ask for one.

csvjoin works on your computer only. It does not change your files and sends nothing over
the internet.
