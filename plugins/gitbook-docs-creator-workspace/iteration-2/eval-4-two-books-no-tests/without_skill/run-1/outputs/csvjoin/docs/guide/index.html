csvjoin

Join two CSV files on a shared column and get the result as CSV. Pick the guide that matches what you need to do.

  • User guide For people who have two CSV files and want one. Install the tool, run your first join, choose which rows to keep.
  • Operator guide For people who install csvjoin on shared machines or run it from scheduled jobs. Deployment, the row limit, exit codes, failure messages.
