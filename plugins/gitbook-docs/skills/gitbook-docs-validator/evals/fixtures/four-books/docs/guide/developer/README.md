## What you will find here

| [II. Contributing](contributing/README.md) | Make a change that will be merged |
| [III. Extending](extending/README.md) | Add behaviour without patching the core |
| [IV. Releasing](releasing/README.md) | Cut and publish a version |
| [Appendix: names in the code](appendix.md) | Look up what a name in the code means |
